# 架构与安全偏差

| ID | 当前偏差 | 风险 | 处理方向 |
| --- | --- | --- | --- |
| GEN-001 | 输出路径虽 absolute+normalize，但未证明统一校验目标根包含和符号链接 | 输入可能导致路径逃逸 | 对所有输出执行 root containment 和 symlink 检查 |
| GEN-002 | 发布资源示例含 `database.password=root123456` | 诱导复制弱凭据并进入发布产物 | 改为明显无效占位符且推荐外部 Secret |
| GEN-003 | 真实数据库生成测试被注释 | 单元模板测试不能覆盖 JDBC、MBG 和完整输出 | 使用容器化隔离数据库增加端到端测试 |
| GEN-004 | 生成结果未机器化记录 Generator/Crafter/Profile 版本 | 难以复现与迁移 | 生成版本清单和项目元数据 |
| GEN-005 | README 对实际模板、参数和数据隔离能力描述偏简略 | 使用者可能误配覆盖和生成范围 | 以源码和 docs 为准更新完整使用契约 |
